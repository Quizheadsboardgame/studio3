# **App Name**: NewtCollect Analytics

## Core Features:

- Daily Sales Dashboard: Displays daily totals, number of cards sold, top-performing seller, and calculated profit based on commission.
- Seller Management & Sales Entry: Allows adding new sellers, removing existing sellers, and recording individual card sales (card name, price) per seller for a given date.
- Interactive Sales Tables: Presents detailed sales records for each seller in tabular format, with options to delete individual sale entries.
- Sales Performance Chart: Visualizes sales totals per seller through a graphical chart to easily identify contributions.
- Sales Record Search: Enables users to search through all recorded sales by card name, displaying relevant transactions.
- Data Export to CSV: Provides functionality to export all sales data into a CSV file for external analysis or record-keeping.
- Market Insights Tool: Utilizes AI to generate a brief summary of the daily sales trends, highlighting top-selling cards or suggesting popular categories based on recent data.

## Style Guidelines:

- Primary color: A confident, deep blue (#2e73cc) to evoke trust and professionalism in a business context.
- Background color: A very light, desaturated blue (#eef5fc) for a clean, calm, and uncluttered visual experience.
- Accent color: A vibrant teal (#69dbdb) to provide a refreshing contrast, drawing attention to interactive elements and important information.
- Body and headline fonts: 'Segoe UI', 'Arial' (sans-serif) for their clean lines, readability, and modern appearance. Note: currently only Google Fonts are supported.
- Implement modern, minimalist line icons for navigation, data actions (add, remove, export), and key dashboard metrics to maintain clarity.
- Maintain a responsive grid-based layout for the dashboard cards, ensuring optimal display across various screen sizes. Utilize clear visual separation for input forms, tables, and tabbed content sections.
- Incorporate subtle hover effects on buttons and interactive elements, and smooth transitions when switching between seller tabs or updating chart data for a polished user experience.
